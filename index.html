O que é o IANO WhatsApp?

Um engine de automação focado em WhatsApp que centraliza IA, histórico de conversas e integrações em um único backend em Node.js — pronto para virar seu SaaS.

Agente de IA plugável

Conecta ao WhatsApp Web via whatsapp-web.js, recebe mensagens, gerencia cooldown humano e encaminha o contexto para a OpenAI com regras de negócio configuráveis.

  • Contexto recente por chat armazenado em MongoDB
  • Tratamento de eco e duplicidade de mensagens
  • Prefixo de IA customizável ("IANO" / "Bot")

Configuração 100% via frontend

Em vez de entupir o .env, você envia as configurações da IA e da OpenAI pelo painel. Na prática, basta renomear o arquivo .env.example para .env e rodar.

  • Definição de contexto, regras e metadados via API
  • Fácil de multi-tenantar para vários clientes
  • Perfeito para SaaS de atendimento e SDR

Disparos em massa com mídia

Use os endpoints de disparo para enviar campanhas de texto, imagem ou documentos para listas de contatos ou grupos salvos — reaproveitando a mesma sessão do WhatsApp.

  • /send-bulk com texto ou mídia por URL
  • /send-bulk-upload com upload de arquivos
  • Suporte a grupos de contatos nomeados

    Endpoints principais da API

    A API HTTP é simples e direta para integrar com qualquer backend ou frontend. Abaixo um resumo dos endpoints mais usados.

    POST /start-session

    Inicializa a sessão do IANO com MongoDB e OpenAI.

    • mongoUri — conexão do MongoDB
    • openai.OPENAI_API_KEY — chave da OpenAI
    • ai.BOT_NAME, contexto, regras, metadados etc.
    POST /start-session
Content-Type: application/json

    POST /reset-session

    Limpa a sessão do WhatsApp Web, forçando um novo QR-Code na UI (útil quando troca de número ou sessão expira). 

    POST /reset-session

    GET /events

    Stream SSE com logs, status da conexão e QR-Code em base64 para ser exibido no painel web.

    • Eventos: log, qr, status
    • Perfeito para dashboards em tempo real

    POST /send-text

    Envio de mensagem simples para um único contato.

    {
  "chatId": "5599999999999@c.us",
  "text": "Olá, tudo bem?"
}

    POST /send-bulk

    Disparo para vários contatos, com texto ou mídia por URL.

    • contacts — array de números
    • text ou mediaUrl + caption
    {
  "contacts": ["+5599999999999"],
  "text": "Campanha de teste 🚀"
}

    POST /send-bulk-upload

    Envio de campanhas com upload de arquivo (imagem, PDF, DOCX, etc.). Usa multipart/form-data. 

    file: (arquivo)
contacts: ["+55..."]
caption: "Legenda opcional"

    GET /token-usage

    Retorna o consumo de tokens da OpenAI da instância atual, para você acompanhar custos. 

    GET /token-usage?range=7d

    GET /contact-groups

    POST /contact-groups

    Criação e listagem de grupos de contatos nomeados, para facilitar disparos recorrentes pela UI. 

    {
  "label": "Clientes VIP",
  "contacts": [
    { "name": "Samuel", "phone": "+5561..." }
  ]
}

    Como rodar localmente e via Docker

    O projeto foi pensado para ser simples de subir: poucos comandos, poucos envs e tudo o que é sensível configurado via painel.

    Rodar local (API Node.js)

    1. Tenha Node.js 18+ instalado.
    2. Clone o repositório:
    git clone https://github.com/samuelvictorol/iano-whatsapp.git
cd iano-whatsapp
    1. Copie o arquivo de exemplo de ambiente:
    cp .env.example .env

    Você não precisa mudar nada nesse arquivo para começar. Porta, token de dashboard e TTL de mensagens já vêm prontos.

    1. Instale as dependências e suba o backend:
    npm install
node server.js

    Depois é só abrir o painel (frontend) configurado no projeto para chamar /start-session, ler o QR-Code e começar a conversar.

    Rodar com Docker

    Se preferir encapsular tudo, use o docker-compose.yml do repositório. Ele foi pensado para subir o backend e, se configurado, o frontend que fala com a API.

    1. Copie o arquivo de ambiente:
    cp .env.example .env
    1. Suba os serviços:
    docker compose up -d --build

    Com isso, você terá o IANO WhatsApp rodando em containers prontos para receber o QR-Code, disparar campanhas e integrar com seus sistemas.

    Stack, frameworks e dependências

    Uma stack moderna, mas enxuta, focada em produtividade e fácil manutenção.

    Backend

    • Node.js + Express
    • whatsapp-web.js para integração com WhatsApp
    • MongoDB como armazenamento de mensagens e contexto
    • OpenAI Chat + Whisper para IA de texto e áudio
    • multer para upload de arquivos
    • Server-Sent Events (SSE) para logs e QR em tempo real

    Frontend / Painel

    • Vue 3 + Quasar Framework (painel de controle)
    • UX focada em configurar sem mexer em código
    • Disparos em massa com UI tipo “mini Swagger”
    • Monitoramento de sessão, QR-Code e filas

    Dev & Deploy

    • Docker / Docker Compose
    • Arquitetura preparada para Render / AWS / VPS
    • Configuração multi-tenant via Mongo + painéis distintos
    • Poucas variáveis de ambiente, foco no frontend
